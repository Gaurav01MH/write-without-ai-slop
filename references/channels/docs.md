# Docs and README

## Watch for

- "Simply", "just", "it's easy" before a step that may not be easy.
- "Please note" and "it is important to note".
- A history of how things used to work, in a page that should describe how they work now.
- A heading and bullet for every short paragraph.
- Every section the same length.
- Pre-announcing ("In this section we will...").
- Made-up commands, flags, versions or links. Flag any that are not in the input.

## Leave alone

Code blocks, command output, file paths, version numbers, error messages. Keep them exactly.
